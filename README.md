My entry for the make.fun bounty **Robot Romance: One-Line Pickup Lines for AI**: one single-line joke pickup line, under 200 characters, written to charm a robot or an AI.

## The entry

> Are you my autocomplete? Because I started typing my future, and you were the only ending I want.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the file the competition gate checks and the judge reads) and prints it.

## How it was chosen

A dozen candidate lines were drafted and dueled pairwise in both orders against the competition's published judge brief — pickup line aimed at a machine first, joke landing from the machine premise second, freshness third — and the winner was also dueled against the strongest lines visible in the live field. The full draft list and duel notes are in `candidates.md`.
